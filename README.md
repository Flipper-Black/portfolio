# Things I Build

A personal collection of projects in software, engineering, and experimental physics.

## Projects

### Barcona Systems
A collaborative project exploring camera-based inventory systems for warehouses, including barcode reading and shelf-location assignment.

[Visit the project website](https://thegreatwave21.github.io/barcona-systems/)

### GYPT — Magnetic Carousel · Problem 16
An ongoing experimental physics project at Phaenovum investigating the magnetic carousel for the German Young Physicists’ Tournament (GYPT).

Further details and selected materials may be shared after completion.

## Local Preview

Clone this repository, open its folder, and run:

```bash
python3 -m http.server 4173
```

Then visit [localhost:4173](http://localhost:4173).
